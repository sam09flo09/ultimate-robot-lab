Robot Lab

Privacy and IT notes

Robot Lab is a robot-programming simulator that runs entirely inside the student's web browser. It has no accounts, no sign-in, and no server of its own. Student work never leaves the Chromebook unless the student saves a file and hands it in themselves.

The short version

  • No accounts. Students never enter a name, email, password or school ID.
  • No data collection. Robot Lab has no analytics, no tracking, no advertising, no cookies, and no third-party scripts.
  • Nothing is uploaded. Programs run in the browser. Robot Lab never sends student code, progress or files anywhere.
  • Students control their files. Work is saved only when a student chooses File → Save. The file goes wherever they put it, for example their own Google Drive, and they turn it in through Google Classroom like any other assignment.

What is stored, and where

To protect against lost work, Robot Lab keeps a few things in the browser's own local storage on that Chromebook. It stays on the device and is never sent anywhere. Clearing the browser's site data removes it.

Project files (.robolab) contain the student's code, the project name they typed, the playground, and any activity progress. They don't contain names, emails or device identifiers, unless a student types one into their code or project name.

Hosting

Robot Lab is a static website: plain files with no database and no server-side code. Like any website, the hosting service (e.g. GitHub Pages) receives ordinary web requests when the app is loaded and may keep standard server logs, such as the IP address and time of the request, under its own privacy policy. Robot Lab itself adds nothing to those requests. After the first visit, the app loads from the offline cache.

Other domainsNone. No CDNs, fonts, analytics or APIs are loaded from elsewhere.
InstallOptional. Chrome can install it as an app (a Progressive Web App) from the address bar. No Chrome Web Store listing, extension or admin-console install is needed.
PermissionsNone requested: no camera, microphone, location, notifications or clipboard access.
OfflineA service worker caches about 3 MB of app files after the first load (the 3D view uses WebGL2, built into Chrome; no plug-ins).
FilesStudents open and save files with the standard ChromeOS file picker. File types: .robolab (project), .robolab-level (challenge), .robolab-activity (lesson). Opened files are checked and cleaned before use, so a damaged or tampered file can't break the app.
